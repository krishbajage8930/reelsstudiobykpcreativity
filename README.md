# Reels Studio by k_p_creativity Portfolio Website

This is a static portfolio website for Reels Studio by k_p_creativity.

## Folder Structure

reels_studio_by_kp_creativity/
- index.html
- assets/
  - logo.jpg

## How to Use

1. Upload this complete folder to GitHub.
2. Connect the GitHub repository to Netlify.
3. Deploy the site.
4. Replace the placeholder work cards with your real thumbnails/videos later.

## Important Edits

In `index.html`, replace:

`https://your-netlify-link.netlify.app`

with your real Netlify website link after deployment.
